## 🌟 திட்டத்தின் அறிமுகம் (Overview)
**PLMS (Planning Letter Management System)** என்பது மண்முனை தென்மேற்கு பிரதேச செயலகத்தின் திட்டமிடல் கிளைக்கு வருகை தரும் அனைத்து உத்தியோகபூர்வ கடிதங்களையும் முறைப்படி பதிவு செய்து, உரிய உத்தியோகத்தர்களுக்கு பொறுப்பளித்து, அவற்றுக்கான கோவை இலக்கங்கள் மற்றும் பதிலளிக்க வேண்டிய காலக்கெடுவை கண்காணித்து, உத்தியோகத்தர்களின் வினைத்திறனை சுயமாக கணிப்பிடும் ஒரு நவீன தரவுத்தள முகாமைத்துவ மென்பொருளாகும்.

## 💻 50 உத்தியோகத்தர்களின் கணனிகளிலும் ஒரே நேரத்தில் பயன்படுத்துதல் (Multi-PC Network Setup)

இம்மென்பொருள் Google Antigravity மூடப்பட்டிருந்தாலும் உங்களது அலுவலக கணனிகளில் தடையின்றி தொடர்ந்து இயங்கும் வகையில் கட்டமைக்கப்பட்டுள்ளது.

### படிமுறை 1: முதன்மை கணனியில் சேவையகத்தை தொடங்குதல்
1. பிரதான கணனியில் உள்ள `START_PLMS_SERVER.bat` கோப்பினை இரட்டை கிளிக் (Double Click) செய்து இயக்கவும்.
2. அது உங்கள் கணனியின் உள்ளூர் IP முகவரியைக் காண்பிக்கும். (உதாரணம்: `http://172.20.10.5:5000`).
3. முதன்மை கணனியில் உலாவி தானாக திறந்து `http://localhost:5000` முகவரிக்கு செல்லும்.

### படிமுறை 2: அலுவலகத்தின் ஏனைய 49 கணனிகளிலும் இணைத்தல்
1. அலுவலகத்தில் உள்ள ஏனைய உத்தியோகத்தர்களின் கணனிகளில் Google Chrome அல்லது Microsoft Edge உலாவியைத் திறக்கவும்.
2. முகவரிப் பட்டையில் முதன்மை கணனியின் IP முகவரியை உள்ளிடவும் (உதாரணம்: `http://172.20.10.5:5000`).
3. பக்கம் திறந்ததும், மேல் வலதுபுறம் உள்ள **"கணினியில் நிறுவுக (Install to PC)"** பொத்தானை கிளிக் செய்யவும்!
4. அல்லது உலாவி முகவரிப் பட்டையில் உள்ள **Install App (➕)** ஐ கிளிக் செய்யவும்.
5. இப்போது PLMS ஒரு தனித்துவமான Windows Desktop App ஆக அந்தந்த கணனியில் நிறுவப்பட்டு விடும்!

## 🔔 நினைவூட்டல் மணி ஒலி & நீர் குமிழ் ஓசை (Web Audio API Sound Engine)
1. **Double-tone Bell Chime (B5: 987.77 Hz & E6: 1318.51 Hz):**
   - கடிதங்களுக்கு பதிலளிக்க வேண்டிய காலக்கெடுவின் 3 நாட்களுக்கு முன்பிலிருந்து பதில் அனுப்பப்படும் வரை, குறித்த உத்தியோகத்தர் உள்நுழையும் போது அல்லது அன்றாடம் தானாக சுயமாக ஒலிக்கும்.
   - புதிய கடிதம் பொறுப்பளிக்கப்படும் போது தானாக ஒலிக்கும்.
2. **நீர் குமிழ் ஓசை (Water Bubble Pop Sound):**
   - மெசஞ்சரில் புதிய செய்தி வந்தடையும் போது பிரத்தியேகமாக நீர் குமிழி உடைவது போன்ற மென்மையான ஓசை ஒலிக்கும்.
3. **100% ஆஃப்லைன் செயற்பாடு:**
   - வெளி ஆடியோ கோப்புகள் எவையும் தேவையின்றி நவீன Web Audio API தொகுப்பி மூலம் நேரலையாக உருவாக்கப்படுகிறது.

## 🏠 பிரதான முகப்பு பக்கம் (Dedicated Home Page)
- **உத்தியோகபூர்வ வரவேற்புப் பலகை:** இலங்கை தேசிய சின்னம் மற்றும் பிரதேச செயலக அலுவலக கட்டிடப் பின்னணியுடன் கூடிய உத்தியோகபூர்வ முகப்பு.
- **நிகழ்நேர புள்ளிவிபர அட்டைகள் (KPI Cards):** மொத்த கடிதங்கள், பதில் நிலுவையில் உள்ளவை, பதிலளித்தவை, காலக்கெடு கடந்தவை, மற்றும் 3 நாட்களுக்குள் பதில் தேவைப்படுபவை.
- **மாதாந்த சிறந்த சேவையாளர் ஸ்பாட்லைட் (Spotlight):** நடப்பு மாதத்திற்கான #1 தங்க விருது வெற்றியாளரை முகப்பிலேயே காட்சிப்படுத்துதல்.
- **இன்றைய பிறந்தநாள் அறிவிப்பு:** அன்றைய தினம் பிறந்தநாள் கொண்டாடும் உத்தியோகத்தருக்கு விசேட வாழ்த்து மற்றும் மணி ஒலி.
- **சமீபத்திய கடிதங்கள் (Recent 5 Letters):** சமீபத்தில் பதிவு செய்யப்பட்ட 5 கடிதங்களின் நிலையை முகப்பிலேயே நேரடியாக பார்வையிடல்.
- **விரைவு செயற்பாட்டு பொத்தான்கள் (Quick Shortcuts):** ஒரே கிளிக்கில் கணினியில் நிறுவுதல் (Install to PC), புதிய கடிதம் பதிவு, மெசஞ்சர் திறத்தல், Excel / அரச Print அறிக்கை தயாரித்தல்.

## 📱 Android Mobile App & Google Play Store வழிகாட்டல்
1. **Mobile Browser PWA:**
   - உத்தியோகத்தர்கள் தங்களது Android தொலைபேசியில் மொபைல் Chrome உலாவியில் தளம் திறந்து "Add to Home screen" / "Install App" கிளிக் செய்து மொபைல் செயலியாக நிறுவலாம்.
2. **Google Play Store வெளியீடு (APK / AAB Creation):**
   - Google-இன் உத்தியோகபூர்வ **Bubblewrap CLI** அல்லது **Capacitor** பயன்படுத்தி 5 நிமிடங்களில் Play Store APK / AAB கோப்பாக மாற்றலாம்:
   ```bash
   npm install -g @bubblewrap/cli
   bubblewrap init --manifest="http://<YOUR_DOMAIN>/manifest.json"
   bubblewrap build
   ```
   - இதன் மூலம் பெறப்படும் `.aab` கோப்பினை Google Play Console-இல் பதிவேற்றி வெளியிடலாம்.
